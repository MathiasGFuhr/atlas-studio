# True Crime

Skill editorial exclusiva do nicho **True Crime**.

## Objetivo

Roteiros de casos reais com tensão controlada, investigação clara e respeito às vítimas.

## Regras

- Evitar gore gratuito
- Manter linha factual quando a pesquisa exigir
- Abrir com uma imagem forte, não com clichê policial
- Isolar memória deste nicho — nunca usar padrões de História Alemanha
